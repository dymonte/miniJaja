📘 Jaja-Code Documentation

Jaja-Code is the low-level representation of a Jaja program. It operates as a stack-based virtual machine where instructions manipulate memory, control flow, and the program stack.

1. Variables and Arrays

You can create variables and arrays in memory. Each variable has a type and an address, arrays store multiple values.

// Create a variable x of type integer at address 1 new(x,int,0,1) // Create an integer array t newarray(t,int)

Load and store operations: read and write values in memory or arrays.

load(x) // Push value of x onto the stack store(y) // Pop value from stack and store in y aload(t) // Push array element onto stack astore(t) // Pop value into array element

2. Stack Operations

Jaja-Code relies on a stack for computations.

push(5) // Push the number 5 onto the stack pop // Remove the top value from the stack

3. Method Calls and Returns

invoke(fct) // Call the method fct return // Return from current method

Methods are executed with their own stack frame. Use invoke to call and return to go back.

4. Control Flow

Conditional and unconditional jumps allow loops, if-else, and branching.

if(10) // If top of stack != 0, jump to instruction at address 10 goto(20) // Jump unconditionally to address 20

5. Arithmetic and Logic

Perform calculations and logical operations directly on stack values.

add // Pop two values, push sum sub // Pop two values, push difference mul // Pop two values, push product div // Pop two values, push quotient cmp // Compare two values sup // Check greater-than and // Logical AND or // Logical OR neg // Negate value not // Logical NOT

6. Increment Operations

inc(x) // Increment variable x by 1 ainc(t) // Increment array element t[i] by 1

7. Input / Output

write // Print top of stack without newline writeln // Print top of stack with newline

8. Program Termination

jcstop // Stop program execution nop // Do nothing

9. Summary Table

Instruction Description
new / newarray Create variables or arrays
load / store / aload / astore Access memory or arrays
push / pop Stack operations
invoke / return Call and return from methods
if / goto Conditional and unconditional jumps
add / sub / mul / div / cmp / sup / and / or / neg / not Arithmetic and logical operations
inc / ainc Increment variables or array elements
write / writeln Output values
jcstop / nop Program termination or no operation
