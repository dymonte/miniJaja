The project

MiniJaja is a lightweight educational programming language that supports procedural concepts with a synthax close to Java described with ANTLR. It includes classes, variables, methods, loops, and conditional statements. The compiled version of miniJaja is called jajaCode.
The interface application created with help of JavaFX allows you to write and interpret programs in miniJaja, compile them in jajaCode and execute them. In addition, RichTextFX is used for the code editor.
It was developed by a team of students from the University of Marie et Louis Pasteur in Besançon, France. The project was carried out as part of the Compilation and Software Engineering courses in the M1INFO program.
