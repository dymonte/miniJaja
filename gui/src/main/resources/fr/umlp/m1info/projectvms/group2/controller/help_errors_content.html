⚠️ MiniJaja & Jaja-Code Errors Reference

This reference lists common errors that can occur during compilation or interpretation of MiniJaja programs, as well as runtime errors in Jaja-Code execution.

1. MiniJaja Compilation Errors

Error Description
UndefinedVariable A variable is used before being declared.
TypeMismatch An operation or assignment uses incompatible types (e.g., assigning a boolean to an integer variable).
MethodNotFound Calling a method that does not exist in the class.
ArraySizeError Declaring an array with invalid or negative size.
DuplicateDeclaration Variable or method is declared multiple times in the same scope.
InvalidReturn A method returns a value when its type is void, or does not return a value when a type is required.
SyntaxError Program does not conform to MiniJaja syntax rules (e.g., missing semicolon, wrong keywords).

2. MiniJaja Runtime / Interpretation Errors

Error Description
NullReference Accessing an array or object that has not been initialized.
IndexOutOfBounds Accessing an array element outside its valid indices.
DivisionByZero Dividing an integer by zero.
UninitializedVariable Using a local variable before assigning a value.
InvalidOperation Performing an operation that is not defined for the type (e.g., adding a boolean to an integer).

3. Jaja-Code Runtime Errors

These errors occur during execution of the compiled Jaja-Code instructions.

Error Description
StackUnderflow An instruction attempts to pop a value from an empty stack.
StackOverflow Too many values are pushed onto the stack, exceeding the maximum size.
InvalidMemoryAccess Accessing a variable or array at an invalid memory address.
ArrayIndexOutOfBounds Accessing an array element with an index outside its bounds.
DivisionByZero Executing a div instruction with a divisor of zero.
UnknownInstruction The interpreter encounters an instruction that is not defined.
InvalidJump A jump instruction (if or goto) targets an invalid or non-existent address.
StackTypeError An arithmetic or logical operation is applied to incompatible stack types.
