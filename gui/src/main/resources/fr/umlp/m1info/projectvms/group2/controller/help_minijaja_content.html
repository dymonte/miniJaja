📘 MiniJaja Language Documentation

MiniJaja is a lightweight, educational programming language that supports object-oriented and procedural concepts. It includes classes, variables, methods, loops, and conditional statements.

1. Class Declaration

A class defines a structure that contains variables (fields), methods, and a special main block that represents the entry point of the program.

class C { int x = 0; int f(int x) { return x + 1; } main { x = f(x); } }

Syntax:
class <ClassName> { [<declarations>] [<methods>] main { <statements> } }

2. Variable Declarations

Variables can be declared inside a class or a method. Each variable has a type, a name, and may have an initial value.

  • int — integer numbers
  • bool — boolean values (true or false)
  • Arrays — for example: int t[4];
int x = 0; bool b = true; int t[4];

Variables declared at the class level are shared across methods (fields), while those inside methods are local.

3. Method Declarations

A method defines a block of code that can take parameters, perform computations, and optionally return a value.

Structure:

<return_type> <method_name>([<parameters>]) { <local declarations> <statements> [return <expression>;] }

Example:

int fct1(int max) { int y = 5; while (max > 0) { y += max; max = max - 1; }; return y; } void fct2(int x) { write("x = "); writeln(x); }

This function computes the sum of all integers from max down to 1, starting with y = 5.

4. Control Structures

If-Else Statement

if (b) { x = fct(x); } else { x = 0; };

The condition b is evaluated. If it is true, fct(x) is called. Otherwise, x is set to 0.

While Loop

while (max > 0) { y += max; max = max - 1; };

The loop executes repeatedly as long as max > 0 is true. Each iteration adds max to y and decrements max.

5. The main Block

The main block is the entry point of the program. When the class is executed, the code inside main runs automatically.

main { if (b) { x = fct(x); } else { x = 0; }; write(x); }

In this example:

  • The program checks the boolean variable b.
  • If b is true, it assigns x = fct(x).
  • Otherwise, x is set to 0.
  • Finally, it calls result(x) to display the result.

6. Assignation

x = 5; x += 5;

// x = x + 5

Assigns a value to a variable.
